## Connexion à l'Application <a name="connexion"></a>

### Accès à l'Application
1. Ouvrez votre navigateur web
2. Accédez à l'URL de l'application
3. Saisissez vos identifiants :
   - Login
   - Mot de passe
4. Cliquez sur "Connexion"

### Rôles et Permissions
- **Administrateur** : Accès complet à toutes les fonctionnalités
- **Responsable** : Gestion des commandes et des produits

## Interface Principale <a name="interface"></a>

### Menu de Navigation
- **Commandes** : Accès à la gestion des commandes
- **Produits** : Gestion du catalogue
- **Mon Compte** : Paramètres personnels
- **Déconnexion** : Quitter l'application

## Gestion des Commandes <a name="commandes"></a>

### Visualisation des Commandes
- Les commandes sont organisées par statut :
  - En attente
  - En préparation
  - À régler
  - Terminées

### Traitement d'une Commande
1. Cliquez sur une commande pour voir les détails
2. Consultez :
   - Produits commandés
   - Quantités
   - Prix total
3. Modifiez le statut selon l'avancement
4. Validez les modifications

### Modification de Statut
1. Dans la vue détaillée de la commande
2. Cliquez sur le bouton du nouveau statut
3. Confirmez le changement

## Gestion des Produits <a name="produits"></a>

### Catalogue des Produits
- Liste complète des produits
- Filtrage par catégorie
- Tri par différents critères

### Ajout d'un Produit
1. Cliquez sur "Ajouter un produit"
2. Remplissez les informations :
   - Nom
   - Catégorie
   - Prix
   - Taille(s)
3. Ajoutez une image (optionnel)
4. Validez l'ajout

### Modification des Prix
1. Localisez le produit dans la liste
2. Cliquez sur l'icône d'édition
3. Modifiez le prix
4. Sauvegardez les changements

## Rapports et Statistiques <a name="rapports"></a>

### Consultation des Rapports
1. Accédez à la section Rapports
2. Sélectionnez la période :
   - Jour
   - Semaine
   - Mois
   - Semestre
3. Visualisez :
   - Ventes par produit
   - Chiffre d'affaires
   - Statistiques détaillées

### Export des Données
- Format PDF disponible
- Données exportables pour analyse

### Gestion des Tailles et Prix
1. Accédez à un produit
2. Gérez les tailles disponibles
3. Définissez les prix par taille
4. Activez/désactivez des tailles

### Gestion des Clients
1. Consultation de la liste des clients
2. Historique des commandes par client
3. Gestion des informations client

### Rapports Détaillés
1. Statistiques par période
2. Analyse des ventes par catégorie
3. Suivi des tendances
4. Export des données
